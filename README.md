# Welcome to MAI
by The Hai Long Nguyen and Andreas Gunnar (2026)

This game was created in the context of the CS-A1110 O1 course. 

A simple text based adventure game inspired by games such as Tunic and Outer Wilds that made us use everything we have learned thus far to make our own project. The game has many secrets, different endings and details to catch while playing the game, however a walkthrough is provided later in this document to help with detailing the world and the steps to get to the secret ending. The game is best played blind and with a curious mind :)

File available publicly online :https://github.com/grapilyfod/o1-project.git

## Guide and Walkthrough

MAI

Story : You are an inventor, and the grandfather of Mai, a 7-year-old girl. After a long day of work, you get home, all tired, and go to bed. But when you wake up, you appear in the middle of a small pond, which encrypted text surrounding you. As you wander around the fantasy village with frog people, you have to get to the top of the clocktower before dawn (turns), while carrying an item that you built to unlock the door. As you progress through the game, you will learn more about the backstory of the character through dialogues with the NPCS and the library books. You have to discover the true objective of the game by building the correct item in the workshop to return home.
